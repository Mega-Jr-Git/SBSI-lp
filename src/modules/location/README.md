# Módulo: Location (Local do Evento)

Este módulo é responsável por renderizar a seção de localização do evento (**Campo Grande • 2027**). Ele apresenta informações sobre a cidade-sede, disponibiliza botões de ação externa para rotas/hotéis e incorpora um mapa interativo da **UFMS (Universidade Federal de Mato Grosso do Sul)**.

---

## Estrutura de Arquivos

Seguindo o padrão de design do projeto, a pasta do módulo está organizada da seguinte forma:

```text
src/modules/location/
|-- LocationSection.tsx     # Componente principal da seção
|-- Location.css            # Estilos específicos da seção
|-- location.data.ts        # Links externos e dados de integração do mapa
`-- README.md               # Documentação do módulo
```
