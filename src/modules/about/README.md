# Módulo Sobre

Exibe as informações institucionais sobre o Simpósio Brasileiro de Sistemas de Informação (SBSI).

## Responsabilidade
- Apresentar o texto sobre o evento e o contexto da edição atual (2027).
- Exibir a logo principal/tema do evento ao lado do texto.

## Estrutura
- `AboutSection.tsx`: Componente React principal.
- `about.css`: Estilos do módulo, usando tokens globais.
- `assets/`: Imagens e SVGs específicos deste módulo (onde será colocada a logo).

## Como Editar
O conteúdo de texto pode ser atualizado diretamente em `AboutSection.tsx`.
